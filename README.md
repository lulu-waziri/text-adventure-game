# Text Adventure Game: The Cave of Shadows

A text-based cave adventure game written in Python. Explore a mysterious cave, collect items, and try to reach the treasure vault, but watch your step. Some paths are safer than others.

## How to Play

You explore the cave by typing commands. Find the **rusty key**, reach the **Treasure Vault**, and unlock the chest to win. Beware of the bottomless pit!

### Commands

| Command | What it does |
|---|---|
| `go <direction>` | Move north, south, east, or west (e.g. `go north`) |
| `take <item>` | Pick up an item in the room (e.g. `take torch`) |
| `inventory` | Show what you're carrying |
| `look` | Describe the room again |
| `help` | Show the list of commands |
| `quit` | Exit the game |

## Requirements

- Python 3.6 or newer
- No extra libraries needed (uses only the built-in `sys` and `time` modules)

## Running the Game

1. Download or clone this repository.
2. Open a terminal or command prompt in the project folder.
3. Run:

```
python text_adventure.py
```

On Mac/Linux, you may need to use `python3 text_adventure.py` instead.
